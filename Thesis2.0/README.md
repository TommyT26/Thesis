# Ανάλυση Συμπεριφορικών Προτύπων Δικτυακής Επικοινωνίας με NetFlow

Μη-επιβλεπόμενη ομαδοποίηση μεταδεδομένων NetFlow από δίκτυο MikroTik.
Διπλωματική εργασία — Φίλιππος-Θωμάς Κουλικουρδής.

## Τι κάνει

Το pipeline παίρνει τα ακατέργαστα αρχεία εξαγωγής NetFlow και βγάζει ένα
αριθμητικό προφίλ ανά host, ομαδοποιεί τους hosts σε συμπεριφορικές ομάδες,
και ελέγχει αν οι ομάδες αυτές είναι πραγματικές ή τεχνήματα του αλγορίθμου.

Οι δύο αναλύσεις είναι χωριστές επειδή τα ερωτήματα διαφέρουν:

- **μακροσκοπική** — οι 123.069 εξωτερικοί hosts, όπου το ερώτημα είναι ποιοι
  ξεχωρίζουν και γιατί,
- **μικροσκοπική** — οι 64 εσωτερικοί hosts του εργαστηρίου, όπου το ερώτημα
  είναι ποιος ρόλος αντιστοιχεί σε ποια μηχανή.

## Εκτέλεση

```
py -m pip install -r requirements.txt
py main.py
```

Χωρίς παραμέτρους ανοίγει διαδραστικό μενού με την κατάσταση των αρχείων.
Εναλλακτικά, απευθείας:

```
py main.py --step all            # όλα τα στάδια από την αρχή
py main.py --step macro micro    # μεμονωμένα στάδια, με τη σειρά του pipeline
py main.py --step macro --k-macro 4   # χωρίς την ερώτηση για το k
```

Στο μενού, το `[M]` τρέχει μόνο την ανάλυση (μοντέλα, έλεγχοι, γραφήματα)
χωρίς την προετοιμασία των δεδομένων, που αρκεί να γίνει μία φορά.

## Προϋποθέσεις

- **Python 3.11+** (το numpy 2.3.5 δεν υποστηρίζει την 3.10)
- αρχείο **`.env`** στη ρίζα, με μία γραμμή:

  ```
  THESIS_SALT_KEY=<τυχαίο κλειδί>
  ```

  Είναι το μυστικό κλειδί του HMAC-SHA256 με το οποίο ψευδωνυμοποιούνται οι
  διευθύνσεις IP. **Όποιος το έχει μπορεί να αντιστρέψει κάθε hash**. 
  Αν χαθεί, τα παλιά hashes δεν αντιστοιχούν στα νέα και το
  pipeline πρέπει να ξανατρέξει από τη φάση `clean`.

  Φτιάξε κλειδί με: `py -c "import secrets;print(secrets.token_hex(32))"`

- τα ακατέργαστα CSV στον φάκελο `data/1_raw/`

## Τα στάδια

| #  |     Στάδιο   |                              Τι κάνει                                            |
|----|--------------|----------------------------------------------------------------------------------|
| 1  |    `clean`   | Επίλυση NAT και ψευδωνυμοποίηση κάθε IP με HMAC-SHA256                           |
| 2  |  `aggregate` | Συνένωση A→B και B→A σε μία ροή· πίνακας δραστηριότητας ανά host/ημέρα/ώρα       |
| 3  |    `verify`  | Επαλήθευση ότι δεν χάθηκαν bytes ούτε ροές στη συνένωση                          |
| 4  |   `features` | Αριθμητικό προφίλ ανά host (15 χαρακτηριστικά στο μοντέλο, 3 ακόμη για ερμηνεία) |
| 5  |   `kselect`  | Έξι δείκτες εγκυρότητας για την τεκμηρίωση του k                                 |
| 6  | `sensitivity`| Πόσο αλλάζουν τα αποτελέσματα αν αλλάξει το ποσοστό ανωμαλιών                    |
| 7  |    `macro`   | Isolation Forest, K-Means και DBSCAN στους εξωτερικούς hosts                     |
| 8  |  `agreement` | Πίνακας συνάφειας Isolation Forest και DBSCAN στο ίδιο σύνολο                    |
| 9  |    `micro`   | K-Means και DBSCAN στους εσωτερικούς hosts                                       |
| 10 | `stability`  | Ομαδοποίηση κάθε ημέρας χωριστά και σύγκριση με Adjusted Rand Index              |
| 11 |   `peers`    | Επανεμφάνιση peers και θυρών: ο έλεγχος που ξεχωρίζει σάρωση από P2P             |
| 12 | `portcheck`  | Τι σημαίνει στην πράξη το `Service_Port` και τι κρύβεται πίσω του                |
| 13 |   `hourly`   | Κατανομή της κίνησης κάθε ομάδας μέσα στο 24ωρο                                  |
| 14 | `visualize`  | UMAP, σύνθεση ομάδων ανά ημέρα, ωριαία προφίλ                                    |

## Έλεγχοι

```
py -m unittest discover -s tests -v
```

24 έλεγχοι, χωρίς επιπλέον εξαρτήσεις. Καλύπτουν τα σημεία όπου ένα λάθος δεν
ρίχνει το pipeline αλλά αλλάζει σιωπηλά τα αποτελέσματα.

## Δομή

```
data/1_raw/            ακατέργαστα CSV (δεν ανεβαίνουν)
data/2_processed/      καθαρισμένα και ψευδωνυμοποιημένα
data/3_bidirectional/  αμφίδρομες ροές + χρονικοί πίνακες
data/4_profiles/       features_global.csv — το προφίλ κάθε host
results/               αποτελέσματα ανά στάδιο, γραφήματα, run_manifest.json
src/                   ο κώδικας
tests/                 οι έλεγχοι
```

Κάθε εκτέλεση γράφει `results/run_manifest.json` με την έκδοση της Python,
τις εκδόσεις των βιβλιοθηκών, όλες τις παραμέτρους και το SHA-256 των
αποτελεσμάτων, ώστε κάθε πίνακας και γράφημα να συνδέεται με τη συγκεκριμένη
εκτέλεση που τον παρήγαγε. Το μυστικό κλειδί δεν καταγράφεται εκεί.
